# V4 Dynamic World Model and PPO: Environment/Data Archive

**Archive status: environment and data freeze; formal collection in progress.** At least 11/168 train and validation scenarios are committed. This release records the V4 100 x 100 civilian search-and-rescue setup with 36 platforms, its frozen 84-train/84-validation/140-test registry, environment/data/world-model/PPO runtime source, focused tests, configuration, protocol, review, and compact engineering evidence.

The review permits the frozen train/validation collection. It does not establish prediction accuracy, PPO quality, safe closed-loop results, or scientific benefit. `V4_POLICY_GPU_WITNESS.json` records one actor and critic update with seeded, untrained fixture world models followed by fresh-process restore; formal world-model and PPO training remain `NOT_RUN`. `V4_TEST_HEADS_INTERFACE_CHECK.json` checks interface batching with untrained CPU fixtures, not prediction quality. The 90-minute `V4_EXECUTION_EVIDENCE_CHECK.json` replay covers public task-queue feasibility only and makes no flight-safety claim. Frozen-test evaluation and analysis are `NOT_RUN`.

The formal collection's live shards and logs, the 22 MB single-scenario integration trace, raw run outputs, GPU witness source archives, checkpoints, caches, and credentials are excluded. The collection progress snapshot records at least 11 committed scenarios; this archive does not include those raw scenario shards. V3.3 outcome evidence remains in the repository history and its prior negative data-gate result is not changed by this archive.

The environment fixture and frozen registry come from the V4 environment freeze; `environment_review.json` binds the approved read-only review to the run configuration and protocol. `COLLECT_SCENARIO_INTEGRATION.json` documents the single-scenario collector path only and is not evidence of completed formal collection. `V4_NEW_DATA_CHECK_20261021.md` records a read-only check of one committed scenario; it does not accept the remaining dataset. Source lineage follows V3.3's public civilian environment and scenario implementation. Dependencies are listed in `requirements.txt`. The selected source tree contains no separate license file.
