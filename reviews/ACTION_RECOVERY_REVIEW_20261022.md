In addition, magnitude and duration normalisation lack a frozen control meaning. A high-level task transfer is distinct from the per-second waypoint command. These facts prevent reliable reconstruction of the current five-dimensional action input from event names alone. Neither next-step displacement nor later branch outcomes may be used to fabricate the missing input.

Continue the current batch unchanged for independently validated gain and state-transition learning. Existing records stay preserved; no whole-batch recollection is prescribed by this finding. True action-conditioned G-WM supervision requires a separately versioned public executor-input record and train-only joint support evidence. The final commands immediately before `backend.step` provide an implementation location for a future source version, not evidence that such a record currently exists or that an unexecuted candidate's effect is known.
