# 第二章 Gain-Gate V2 执行计划

计划版本：`gain-gate-v1-100x100`。冻结时间：2026-10-17 04:05:02 UTC。执行代理负责实现、测试、采集和整理证据；主协调者负责只读审核并决定 `PASS / REPAIR / STOP`。执行代理不自评阶段通过。尚未执行的阶段标为 `NOT_RUN`。

## 研究边界

暂定题目：**基于事件感知世界模型与预期净收益评估的异构无人机集群任务分配实时重构方法**。先验证净收益是否存在、是否可预测、是否值得预测；只有轻量门控过关后，才进入图模型、事件感知模型及冻结 PPO 重构器迁移。减少调用次数或降低离线误差不能单独证明方法有效。

现有公开 C1 初始分配适配器不是用户第一章完整求解器。`Public-C1-Catalog-Replanner-v1` 是在公开 C1 优先级和现有合法候选生成器上新建的适配重构器，不声称全局最优。事件检测、100x100 民用模拟器、轨迹复算和图/PPO框架只作为可复用工程来源；旧六场景仅作为回归 pilot。未核验的文献只作查证线索，不能写成已确认创新或首创。

## 在线链路和重构器

公共遥测更新后执行现有事件检测和安全检查。无事件时继续当前队列。安全关键事件绕过冷却和收益门控，立即安全处置，必要时调用重构器。普通候选事件先计算低成本公共特征和收益预测；仅门控通过才进入正式候选搜索。特征不得含完整候选目录、重构结果、模拟器真值、未来任务表、场景/状态哈希或身份字段。

候选生成、合法性过滤、公开评分、约束修复和选动作都在 `Public-C1-Catalog-Replanner-v1` 调用内。最多16个合法候选，可少于16；NOOP保留当前队列执行。重构器优先找影响域内合法替代，无局部替代或公共规则要求全局处理时再扩展全局候选；按当前可见任务、队列、距离、能力、库存、能量和通信评分，平局以稳定动作键排序。不读取模拟器未来 rollout、未来事件或 oracle。合作子任务作为原子动作。记录实际候选数、重复动作、拒绝原因、正式调用计数。抑制普通事件时调用数必须为0。

计算期间当前任务继续执行；命令生效前重新校验，过期动作拒绝并记录。仿真使用分钟步，但CPU耗时按真实单线程时间统计，不能把毫秒成本一律记成一分钟，也不能据此宣称真实飞行实时优势。全部方法在线成本包含检测、特征、推理、安全、候选生成与选动作、修复、通信、切换和命令等待。已计入执行评分的消息/切换不得再次算入重规划成本。

## 配对标签与收益公式

每个决策点保存完整私有快照，只向模型暴露公共投影。同一时间、快照、随机状态及相同未来扰动后缀分别运行 keep 和调用固定重构器。首次动作之后，两分支维持各自队列，只执行同一安全应急规则。标签描述本次调整对30分钟窗口的影响，不代表所有未来重规划策略。默认H=30分钟，episode末截断；另做15/45分钟敏感性。未知结果必须带有效性掩码和原因，不能补零。每状态K=2条配对后缀；训练状态中20个改用K=8检查方差。后缀不是独立样本，随机性按`(suffix_seed,event_class,entity_id,minute,draw_kind)`寻址。

定义`G = J_keep - J_replan - C_replan`，其中`J`越低越好。两臂采用相同的逻辑任务全集：快照时可见任务，加上抽样未来后缀中窗口内新到达的任务；事件外生取消且取消前未完成的任务从两臂分母同时移除。每个任务在首次公开时冻结优先级，新到达任务用到达时优先级；同一任务全集和归一化权重用于两臂。拆分/合作子任务回收到一个逻辑父任务。

单独报告窗口末加权完成率`weighted_completion = sum(p_i * completed_i)`，其中`p_i = priority_i / sum(priority_j)`，完成按窗口末二值判定。窗口末完成成本为`1 - weighted_completion`；另加窗口末未完成逻辑任务的`sum(p_i * remaining_work_fraction_i)`。完成损失衡量是否完成，残余项区分部分进展与没有进展；两项都是设计上有意保留的不同项，各只计算一次，残余不得逐分钟重复累计。两项合计乘完成权重1.0。`J`再加延误分钟×0.2、执行能耗单位×0.01、风险单位×0.25，并保留原始物理量。

`C_replan`加规划CPU秒×0.01、未在`J`记账的重规划通信消息×0.01、分配/队列切换×0.05、调用×0.05、重构规模×0.01。CPU权重敏感性为0、0.001和0.1。命令等待/过期后的任务执行影响计入`J`。成本审计逐项标明执行/规划类别，避免重复计数。权重是仿真评分设计值，不代表真实货币成本。

未来后缀由冻结随机生成器条件于快照前已公开历史采样；保留已发生事件，丢弃输入情景中未采样的未来 tape。每条后缀记录生成器版本、条件状态、seed和tape哈希。初始每分钟采样率作为设计参数固定为：任务到达0.05（从隐藏任务模板中抽取）；平台故障/能力变化每平台0.003；能耗异常每平台0.002；通信退化每链路0.003；环境/障碍事件每区域0.002。模型不得读取这些隐藏后缀。

## 场景、拆分与模型

Pilot复用六个旧父场景，每父场景三个确定生成实例，只用于smoke。正式分布内七类：无/轻扰动、任务新增或信息更新、平台故障/能力变化、能耗异常、通信退化、环境阻塞/速度变化、复合扰动。每类分别生成40个训练、12个验证、20个测试独立实例；位置、兼容能力、任务负荷/期限和事件时间按冻结范围随机化。OOD包括高任务到达/高能耗、低通信、10平台/30任务、20平台/60任务、能力组合变化及空间分散，每项目标20个独立实例。旧模板不能替代正式独立场景。

采集轨迹由 Existing-ET、4分钟周期重构、随机允许/抑制普通事件约各三分之一构成。每轨迹至多用确定性蓄水池抽样取8个候选状态；保留正、零、负收益、NOOP和失败分支。场景、轨迹及所有分支/后缀只能属于一个split。训练做分组折，验证分为模型/阈值选择和区间校准，测试封存。状态身份、场景ID、私有哈希、未来事件tape和未来任务清单不得作为特征。超规模输入必须明确拒绝，禁止静默截断。

模型顺序：常数均值、Ridge、梯度提升树（深度3/5，固定有限调参）、64-64 Gain-MLP（Huber加正收益分类辅助头）、Graph-Gain、条件式 Event-Gain-WM。MLP使用Adam、学习率0.001、batch32、最多100 epochs、验证耐心10，seed 8201/8202/8203；归一化只拟合训练集。先预测净收益均值；独立校准集残差分位数用于保守下界，不将三个初始化的方差冒充校准不确定性。事件模型必须预测一步动态/事件，30分钟终点预测不得改名为一步世界模型；额外动态标签采集成本单列。

进入复杂模型前要求：普通事件至少30个独立正收益和30个非正收益状态；训练分组折优于常数基线；配对Oracle显示存在决策空间；特征加门控中位时间不超过重构器中位时间20%。不满足可做一次有记录且升版的场景/特征修订，仍失败则停止世界模型路线。

## 对照、统计和阶段门

对照包括 Periodic、Existing-ET、Risk-ET、Heuristic-Gain、Gain-Tree、Gain-MLP、Graph-Gain、条件式 Event-Gain-WM，使用相同重构器和安全规则；Oracle-Gain仅用于离线配对状态诊断。消融覆盖事件辅助目标、树/MLP/图、直接收益/双成本头、校准下界/均值门槛、成本项、15/30/45分钟窗口及扰动强度/规模。不移除安全规则做危险闭环消融。PPO迁移和其他重构器更换必须重新采集收益标签。

主要终点：端到端`J_total`、加权完成率、期限违约、可控硬约束违反、安全事件处置。次要终点：规划调用与有效变化、普通事件抑制/无效规划、漏掉有益重构及regret、消息/切换/规模/能耗、全链路均值/p95、区间覆盖、离线采样及训练成本。统计独立单位为场景实例，方法按实例配对；seed为交叉重复，窗口、分支、后缀不扩大N。报告均值/标准差、配对效应、10,000次分组bootstrap 95%区间、配对置换检验；主要比较Holm校正。

预注册方法支持条件：安全强制处理率100%；没有新增可控硬约束违反；相对 Existing-ET 的加权完成率差95%区间下界高于−2个百分点；`J_total`配对95%区间支持正收益。否则报告权衡、不确定或不支持。工程通过与科学有效分开判定。

- P0：来源/复用审计、逐文件hash、配置、协议和tracker；主协调者审核后进入P1。
- P1：合作子任务原子性、NOOP队列执行、周期安全覆盖、完整快照/恢复/重放、计算延迟/过期、成本分项及6×3 smoke。
- P2：标签分布/方差/强制事件/Oracle空间诊断，训练常数、Ridge、树、MLP和新进程恢复。
- P3：无世界模型闭环、冻结阈值后测试/OOD评估。
- P4：有信号时再做图模型/一步事件感知模型和开销对照。
- P5：冻结 PPO 重构器为新版本，重新采集对应keep/replan标签。
- P6：独立轨迹复算、统计/泄漏/资源审计、脱敏及归档回读。

每次失败保留首错、日志、配置、工作量、资源账本和hash；用新run ID重跑，不能覆盖失败证据。总预算24 CPU小时；单服务器任务2小时/8 GiB RSS；先本地smoke、单线程CPU、CUDA关闭。不得擅自租机或增加付费资源。审核记录真实模型和证据范围；文献核验完成之前不得声称研究首创。
