# wm_ppo_v1 event graph scope report

The public-history contract now carries public event history, optional known applied action, public node join keys, and task ownership. Join keys are used only to build platform-task edges. Node features remain numeric public attributes; hidden targets, future tapes, scenario identifiers, and raw IDs are excluded.

`public_projection_to_frame` consumes the compact capture contract: every entry in the activated `public_tasks` mapping becomes a task node, including unassigned and completed tasks. Assignment and queue data are joins only. Legacy sparse projections can still produce queue nodes, marked with `task_public_data_known=0`. Task and platform zone IDs create same-zone and four-neighbor geographic edges using the compact 3x3 row-major zone layout. Missing or invalid zones create no geographic edge; no communication edges are asserted. Observations and public events are admitted only once available by the frame time, and event timestamps must also be no later than that time.

The collator pads node and edge tensors with masks and carries event/action features. There is no silent node truncation. The model applies masked typed-edge message passing, includes current public events in the recurrent state, conditions only the dynamic head on action features, and keeps the gain head on an independent pre-action recurrent representation. One-step target values and per-target masks remain unchanged; gain remains an independently supplied optional endpoint label.

The three positional `forward(node_features, node_mask, sequence_mask)` arguments remain accepted. New graph/event/action arguments are optional for call compatibility. Model state dictionaries are not checkpoint-compatible with prior `EventAwareWorldModel` instances because message-passing, event-encoder, and action-conditioned layers add parameters and change the dynamic-head shape. Existing checkpoints require retraining or explicit migration.

Training remains `NOT_RUN`. The existing `restore_and_compare` helper loads one checkpoint twice in the same process; it does not compare pre-save predictions with a fresh-process restore. `save_checkpoint` also omits optimizer, normalization, and RNG state, so this helper is not evidence of protocol-level training recovery. A future real training path must save those states and verify fixed-input predictions in a new process. The likely public source is the already captured per-second `formal_collection_v1/run_capture.py` trajectory stream plus public events and manifest, read incrementally to form adjacent public-only windows. Do not duplicate the full trajectories on disk; missing queue fields remain masked rather than reconstructed from later frames. Training remains gated on the 30/30 acceptance gate.

Validation is limited to one focused structure test against a compact projection mapping, plus the affected public-dynamics tests. It covers unassigned task retention, legacy unknown task metadata, zone relations without geometry, missing-zone edge exclusion, delayed/future event filtering, hidden-field isolation, padding-node masking, and action isolation from the gain path. `applied_action` is optional and absent fields stay masked.
