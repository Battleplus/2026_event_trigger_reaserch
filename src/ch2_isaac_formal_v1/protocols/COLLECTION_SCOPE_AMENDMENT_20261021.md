# 第二章目标修订：精简采集范围

生效依据：用户2026-10-21明确要求修改目标。本修订用于后续采集版本；
不修改正在运行的 formal-168-v1，不删除或覆盖已采集数据，不改变收益门槛、
场景隔离、评价标准及研究问题。

## 修订后的数据目标

只采集影响任务分配、重构收益和世界模型学习的信息，同时保留必要的公平
配对、安全后果复算及复现证据。

| 保留内容 | 具体字段 |
| --- | --- |
| 平台状态 | 位置、机型、能力、可用性、剩余能量、通信状态、所属区域 |
| 任务状态 | 任务位置、允许机型、优先级、期限、进度、当前分配和队列 |
| 突发变化 | 任务新增、故障、通信变化、能耗异常、影响通行时间的环境变化 |
| 分配决策 | 触发原因、是否重构、执行动作、命令生效时间 |
| 后果与成本 | 完成、延误、失败、安全处置、能耗、规划耗时、通信和切换 |
| 学习与复现 | 公共状态前后变化、配对快照、seed、版本与哈希 |

## 存储与信息隔离

- 地形、140棵树、模型外观和固定配置等共用信息只保存一次，轨迹通过版本或
  哈希引用，不逐行复制。
- 完整公共观测列表不逐行重复保存。保留观测变化、生成时间与可用时间及其
  必要引用，以恢复当时实际可用的公共状态。
- 隐藏目标真值独立保存，仅供评估；不进入策略或世界模型输入。
- 保留必要的位置增量、事件记录及一步公共状态变化。不能简单降低位置
  采样频率而漏掉发现、暂停、能耗变化或世界模型一步监督。
- 配对状态必须仍可恢复，keep/replan仍共享快照、外生后缀和安全规则。

## 实施边界

本次仅修改目标与采集合同，没有部署新的采集程序。后续精简实现使用独立
版本身份，不回写当前批次。未记录或不足以证明的字段保持未知，不能从
精简日志中臆造任务队列、安全处置或其他后果。

研究终点保持：工程是否成立、是否达到30/30、事件触发和收益门控是否改善
任务质量与总成本、世界模型与强化学习是否值得保留。仍以实际实验给出
支持、无优势或证据不足，精简存储本身不是方法有效性的证据。
