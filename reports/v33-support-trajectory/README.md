# V33 observed cross-region trajectory

The representative state was selected at generation time by stable `scenario_id` / event `time` / `state_id` scanning of the then-committed snapshot. This case is now frozen; later shard additions and the expanded cross-region definition have not been globally rescanned and reordered. It was not selected by gain. Its status as the first eligible case across the entire run has not been independently confirmed.

The markers connect consecutive recorded public observation positions for the receiving platform from the selected replan arm's matched counterfactual trace. All 30 available public observation nodes are shown, with consecutive duplicate `(time, x, y)` records removed. These are sampled positions; the connecting strokes do not assert a continuous route or a rescue completion. No truth endpoint is shown in this artifact.

Candidate ordering is ascending `selected_public_cost_estimate`, with ties broken by the canonical full action SHA-256. Cross-region classification includes either assignment outside a task's home region or a donor-to-receiver transfer across regions. This is one selected action, not evidence of a cross-region treatment effect. Forced is false and the label and pair gain masks are true for this state; the recorded gains belong to this state/pair and do not establish general benefit.
